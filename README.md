# PhishGuard AI
**🚀 Real-Time Phishing Risk Detection Using Heuristics & AI-Ready Architecture**

📌 Overview
PhishGuard AI is a real-time phishing detection system that analyzes URLs using heuristic risk scoring and AI-inspired prediction models. It provides a dynamic threat score, graphical risk visualization, and detection logs for transparency.

🚀 Features
* URL length anomaly detection
* Suspicious keyword analysis
* Risk scoring engine
* AI-based phishing prediction
* Graphical risk meter
* URL history tracking
* Real-time analysis

🛠️ Tech Stack
Backend: Python, Flask
Frontend: HTML, CSS, JavaScript
ML: Scikit-learn (Prototype Model)

⚙️ How to Run

Backend:
cd backend
pip install -r requirements.txt
python app.py

Frontend:
cd frontend
python -m http.server 8000

Open in browser:
http://127.0.0.1:8000

🌍 Future Scope
* Browser extension integration
* Real phishing dataset training
* WHOIS & SSL verification
* Enterprise-level API deployment
